# ZecTrix EPD Panel 固件操作手册

> 适用固件：`zetrix_epd_panel`（纯 C 移植版，SSD2683 四色墨水屏 400×300）
> 文档版本：1.0（2026-08）

---

## 1. 设备概览

ZecTrix EPD Panel 是一台基于 **ESP32-S3** 的 **4 色电子墨水屏**（黑 / 白 / 红 / 黄，400×300 像素）智能桌面设备，支持：

- **19 个内置页面**：天气、相册、电子书、日历、老黄历、新闻、WiFi 状态、设置等
- **Wi-Fi 联网**：SNTP 校时（北京时间）、局域网传图、天气数据自动获取（已接通和风天气 API）
- **局域网传图**：手机 / 电脑浏览器直接上传图片到墨水屏
- **AP 直连传图**：无路由器时创建热点（`InkScreen-AP`）传图
- **扫码挪车**：生成 `tel:` 二维码，扫描即可呼叫车主
- **NFC 碰一碰**：手机触碰即可配置 / 读取设备信息（Touch & Go）
- **深度睡眠**：省电模式 + 定时休眠，BOOT 键唤醒

> 注意：墨水屏刷新较慢（全屏刷新约 15~20 秒）。刷新期间画面保持，按键响应会等待刷新完成。

## 2. 按键操作

设备有 **3 个物理按键**：

| 按键 | GPIO | 功能 |
|------|------|------|
| **UP**（上） | GPIO39 | 上一项 / 向上移动 / 上翻页 |
| **DOWN**（下） | GPIO18 | 下一项 / 向下移动 / 下翻页 |
| **BOOT**（确认） | GPIO0 | 确认 / 进入 / 打开详情 / 全屏刷新 |

### 2.1 全局按键（所有页面通用）

| 操作 | 功能 |
|------|------|
| **UP 短按** | 交给当前页面（通常向上 / 上一个） |
| **DOWN 短按** | 交给当前页面（通常向下 / 下一个） |
| **BOOT 短按** | 交给当前页面（通常确认 / 打开） |
| **UP 双击** | 打开 / 关闭 **快速切换**（Quick Switch）面板 |
| **DOWN 长按** | 直接进入 **设置** 页面 |
| **BOOT 长按** | 交给当前页面（相册页=进入传图模式；传图页=退出） |

### 2.2 快速切换（Quick Switch）

在任何页面 **双击 UP** 打开快速切换面板，用 **UP / DOWN** 选择目标页面，**BOOT** 进入。面板含 15 个常用页面：

相册 → 设置 → 天气 → 热点 → 电子书 → 日历 → 老黄历 → 人生进度 → 年度进度 → 日志 → 对齐测试 → 字体指标 → WiFi状态 → 扫码挪车 → 用量统计

> 其余页面（天气详情、照片详情、传图模式）通过所在页面的 BOOT 操作进入。

## 3. 页面详解

### 3.1 相册（Gallery）⭐ 默认页

开机默认进入相册。左侧为文字卡片（标题 / 文案 / 日期 / 地点），右侧为照片预览。

| 操作 | 功能 |
|------|------|
| UP / DOWN 短按 | 切换照片 |
| BOOT 短按 | 进入全屏查看 / 退出全屏 |
| BOOT 双击 | 打开删除确认框（UP/DOWN 选择 删除/取消，BOOT 确认） |
| BOOT 长按 | 进入 **AP 传图模式**（见 §6.2） |

照片通过局域网 / AP 网页上传（见 §6）。支持 **1bpp 黑白** 和 **2bpp 四色（BWRY）** 两种格式，自动缩放填充。

### 3.2 照片详情（Photo Detail）

最大化显示单张照片（无状态栏 / 边框的纯图片视图）。

> 访问方式：当前固件**无全局按键入口**直接切到本页（C++ 版的 BOOT 双击切换已禁用）。页面保留在 UI 管理器中，供应用层代码通过 `ui_manager_switch_page(UI_PAGE_PHOTO_DETAIL)` 调用。

| 操作 | 功能 |
|------|------|
| UP / DOWN 短按 | 上一张 / 下一张 |
| BOOT 短按 | 打开元数据面板（标题 / 日期 / 地点 / 文案） |
| BOOT 短按（面板打开时） | 关闭面板 |

### 3.3 天气（Weather）

显示当前天气三卡片（城市 / 温度 / 空气质量）+ 天气图标 + 湿度 / 风向 / 风力 / 紫外线 + 4 日预报条。

| 操作 | 功能 |
|------|------|
| UP / DOWN 短按 | 在预报日之间切换（高亮选中） |
| 长按（UP/DOWN/BOOT） | 请求刷新天气数据 |

> **当前状态**：天气数据由固件自动周期性拉取并展示（已接通和风天气 API）。无数据时显示"暂无天气数据"。

### 3.4 天气详情（Weather Detail）

24 小时温度曲线 + 小时详情。

> 访问方式：当前固件**无全局按键入口**（C++ 版的 BOOT 双击天气↔详情切换已禁用）。页面保留在 UI 管理器中，供应用层代码调用。

| 操作 | 功能 |
|------|------|
| UP / DOWN 短按 | 选择小时（曲线上的点高亮） |
| BOOT 短按 | 打开选中小时的详情（温度 / 天气文本） |
| BOOT 短按（详情打开时） | 关闭详情 |

TXT 阅读器，支持横屏 / 竖屏两种阅读模式。

**文件列表模式：**

| 操作 | 功能 |

## 4. 设置页面

**进入方式**：任何页面 **DOWN 长按**，或快速切换中选择"设置"。

采用分类菜单结构（左侧分类 / 右侧选项）：

| 分类 | 选项 | 说明 |
|------|------|------|
| **系统** | 重启 | 立即重启设备（BOOT 确认） |
| **相册** | 轮播间隔 | 循环切换：关闭 → 5min → 10min → 30min |
| **网络** | Wi-Fi | 开关 Wi-Fi（连接中 / 已连接 / 未连接） |
| | 局域网服务 | 开关局域网传图 HTTP 服务 |
| | 局域网IP | 显示当前局域网 IP（只读） |
| **系统** | 省电模式 | 手动进入深度睡眠 |
| **关于** | 固件 | 固件版本号（只读） |

### 4.1 设置操作

| 操作 | 功能 |
|------|------|
| UP / DOWN 短按 | 在选项间移动 |
| BOOT 短按 | 激活当前选项（切换 / 执行） |
| UP 长按 | 退出设置，返回相册 |

### 4.2 设置项详细行为

- **轮播间隔**：每按一次循环切换 关闭 → 5 → 10 → 30 分钟。开启后相册全屏模式按周期自动换图，同时**暂停自动睡眠**。
- **Wi-Fi 开关**：
  - 开启：开始连接（显示"连接中"）。
  - 关闭：断开 Wi-Fi，同时关闭局域网服务，显示"未连接"。
- **局域网服务**：需先连接 Wi-Fi。开启后可通过浏览器访问 `http://<设备IP>/?token=<访问令牌>` 传图。开启时**暂停自动睡眠**；**连续 30 分钟无任何请求会自动关闭**（防止忘关耗电）。
- **刷新间隔**：每按一次循环切换 30 → 60 → 120 分钟，控制非对齐页面的定时唤醒周期。日历等对齐型页面按内容变化自动刷新，不受此间隔影响。
- **省电模式**：立即停止服务 → 断开 Wi-Fi → 进入深度睡眠，按 BOOT 唤醒（见 §7）。

## 5. 状态栏

屏幕顶部状态栏（所有页面通用）：

```
[WiFi信号][服务器*][蓝牙]  日期 周几        页面标题        时间  [电池]
```

| 元素 | 说明 |
|------|------|
| WiFi 信号条 | 4 格信号；未连接显示叉号 |
| 服务器标记 | `*` = 局域网 HTTP 服务运行中；未连接时显示空心方框 |
| 蓝牙 | 蓝牙开启时显示图标 |
| 日期 / 周几 | 默认 `M月D日 周X`；支持 ISO / 隐藏格式 |
| 页面标题 | 中央显示当前页面名（电子书/日历会显示附加信息） |
| 时间 | 七段数码管样式 `HH:MM` |
| 电池 | 电池图标（低电量变红）；外接供电时显示充电状态 |

> 时间由 RTC（PCF8563）提供，联网后 SNTP 自动校准为北京时间（CST-8）。

## 6. 图片传输

### 6.1 局域网模式（推荐）

前提：设备已连接 Wi-Fi。

1. 打开 **设置 → 局域网服务**（或相册页 BOOT 长按）。
2. 记下状态栏 / 设置中的设备 IP（如 `192.168.23.213`）。
3. 手机 / 电脑浏览器访问 `http://<设备IP>/`。
4. 网页支持：
   - **上传图片**：选择 1bpp 黑白 或 2bpp 四色 → 预览 → 发送。
   - **轮播周期**：设置 关闭 / 5 / 10 / 30 分钟。
   - **管理照片**：列表查看、删除、编辑元数据（标题 / 日期 / 地点 / 文案）。
   - **关闭服务**：停止局域网服务。
   - **关闭并省电**：停止服务 + 断开 WiFi + 深度睡眠。

> **访问令牌（token）**：局域网模式所有写操作（上传 / 删除 / 设置）需要认证。网页自动从设备获取本机唯一 token 并携带，无需手动输入；脚本调用时需在请求头加 `Authorization: Bearer <token>`。token 首次使用时生成并存储在设备 NVS 中，每台设备不同。

### 6.2 AP 直连模式（无路由器）

1. 在 **WiFi 页 BOOT 长按**，进入传图模式。
2. 设备创建热点 **`InkScreen-AP`**，密码 **`12345678`**。
3. 手机连接该热点。
4. 浏览器访问 **`http://192.168.4.1`**，上传界面与局域网模式相同（AP 模式沿用热点密码保护，无需 token）。
5. **BOOT 长按** 退出传图模式，返回相册。
6. 传输进行中切走页面不会中断上传（服务保持到传输结束）；空闲时切走页面传图服务自动停止。

### 6.3 图片格式支持

| 格式 | 说明 |
|------|------|
| **1bpp 黑白** | 单色位图，每像素 1bit |
| **2bpp 四色（BWRY）** | 黑 / 白 / 红 / 黄，每像素 2bit（与屏幕原生格式一致） |

上传的图片自动缩放适配 400×300 屏幕（cover 模式裁剪），并在相册中按上传顺序显示。

## 7. 睡眠与省电

### 7.1 手动省电

设置 → **省电模式**：停止所有服务 → 断开 Wi-Fi → **深度睡眠**。

- **唤醒**：按 BOOT 键，或插入充电器（充电插入唤醒）。
- 唤醒后自动恢复上次睡眠前的页面并刷新，活动 LED 闪烁提示。

### 7.2 定时自动睡眠（Sync Sleep）

设备联网后按配置的间隔（默认 30 分钟，可在 **设置 → 刷新间隔** 调整为 30 / 60 / 120 分钟）自动进入深度睡眠，BOOT 或 RTC 闹钟唤醒。

**页面差异化唤醒策略**：

- **日历页**：对齐到每天 00:01 自动唤醒刷新（内容只在日界变化），节假日缓存命中时唤醒不联网，夜间零闪烁。
- **相册页**：轮播开启时按轮播间隔唤醒翻页，唤醒不联网。
- **其他页面**：按刷新间隔定时唤醒拉取数据。

**自动睡眠会被以下情况跳过：**

- 局域网 HTTP 服务运行中（连续 30 分钟无请求后自动关闭）
- 充电中（充电状态稳定 60 秒后抑制自动睡眠；手动省电不受影响）

### 7.3 低电量保护

> **计划功能**：当电量低于 3% 时，固件将在 EPD 上强制全屏渲染"电量耗尽，请充电"警示卡片，防止墨水屏留存过期画面，随后关闭硬件电源轨（`board_power_vbat_off`）。当前 C 版固件**尚未实现**低电量检测与警示逻辑，硬件切断 API 已就绪。
> 硬件供电：EPD（GPIO6）、音频功放（GPIO42）电源轨在睡眠时被硬件切断（Power Gating），杜绝漏电。

## 8. 蓝牙与 NFC

### 8.1 蓝牙（BLE）

设备启动时自动开启 BLE 广播，支持：

- **图片推送（Touch & Go）**：手机通过 BLE 推送背景图片，自动保存到相册。
- **NDEF 标签编程**：配合 NFC 功能发布 Touch & Go 标签。

### 8.2 NFC 碰一碰（GT23SC6699）

- 设备上电时自动发布 Touch & Go NDEF 标签。
- 手机 NFC 触碰设备可读取 / 触发配网流程。
- NFC 场检测引脚（GPIO7）作为外部唤醒源从深度睡眠唤醒设备（**计划功能**，当前固件仅支持 BOOT 键唤醒）。

## 9. 常见问题（FAQ）

**Q1：屏幕长时间无变化，按键无反应？**
墨水屏全屏刷新约 15~20 秒，期间按键会排队等待。若超过 2 分钟仍无响应，长按 BOOT 唤醒或重新上电。

**Q2：天气显示"暂无天气数据"？**
和风天气 API 客户端已在 main 初始化并自动拉取。请检查 Wi-Fi 连接是否正常，以及和风天气 API Key 是否配置正确。

**Q3：上传图片后相册没看到？**
确认上传成功提示；刷新相册页（切换离开再回来，或 BOOT 进入全屏再退出）。

**Q4：如何修改车主电话（扫码挪车）？**
NVS 键 `settings/car_phone`，默认 `13800000000`。需通过应用层代码或工具写入。

**Q5：如何修改自动睡眠间隔？**
设置 → **刷新间隔**（30 / 60 / 120 分钟循环）。NVS 键 `sync/sync_interval`（分钟）仍可直接写入，设为 0 关闭自动睡眠（高级用法；日历等对齐型页面不受影响，仍按内容变化唤醒）。

**Q6：开机显示什么页面？**
默认主页面。若上次为深度睡眠唤醒，唤醒后恢复上次睡眠前的页面。

**Q7：局域网服务打不开？**
确认设置中"局域网服务"为开启状态，且设备已获取 IP（状态栏 WiFi 满格 + 设置中局域网IP 非"未获取"）。服务开启时状态栏显示 `*` 标记。注意：连续 30 分钟无请求服务会自动关闭，重新开启即可。

**Q8：AP 模式连不上？**
热点名 `InkScreen-AP`，密码 `12345678`，IP `192.168.4.1`。确认手机已连接该热点（设备同时断开原 Wi-Fi）。

**Q9：日历页显示"更新于昨天"？**
上次数据拉取失败（网络断开或接口超时）后退避入睡，页面保留了最后一次成功数据。检查 Wi-Fi 后长按任意键触发手动重拉，或等待下次对齐唤醒自动刷新。

**Q10：日历页显示"时间未同步"或半夜不刷新？**
RTC 时钟（PCF8563）失效（如后备电池掉电）时的保护行为：设备保持上一画面不刷新错误日期，夜间唤醒后自动重试（最多 3 次，每次 5 分钟，不联网），仍失败则等待按键唤醒。联网 SNTP 校时成功后日历自动恢复当天月份；期间日历页会短暂显示"时间未同步"提示。若该提示反复出现，请检查 RTC 后备电池。
